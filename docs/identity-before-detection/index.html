What this project is

Before anyone can detect suspicious behaviour or investigate an incident, they need to know who the users are, what those users should be able to reach, and what normal looks like. This project builds that understanding first, then layers devices, protection, monitoring and response on top of it.

The business at the centre of it is Via Wash, a laundry and dry-cleaning pickup and delivery business in development, starting in London. Its customer app was already being built before this project started, so the business isn’t invented for the exercise. Its IT, though, is designed and tested in a Microsoft test environment first. Nothing here is a live production system yet.
