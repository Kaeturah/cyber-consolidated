## What this step is

An access request process, possibly using Entra access packages, so access is requested, approved and reviewed.

## Why it matters for Via Wash

Access granted informally is access nobody can account for. A process keeps exceptions visible and temporary.

## What will be done

- Define who can approve which access
- Test a request from start to finish
- Set an end date or review for granted access

## How it will be checked

- A test request is approved and recorded
