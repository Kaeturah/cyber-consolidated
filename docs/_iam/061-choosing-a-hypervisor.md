## What this step is

Choosing the hypervisor, the software that runs virtual machines, and checking the host computer can support it.

## Why it matters for Via Wash

Without Hyper-V on Windows 11 Home, the choice of hypervisor decides how the lab’s networking works and how many machines can run at once.

## What will be done

- Compare options such as VirtualBox and VMware Workstation
- Check the host’s CPU virtualisation support, memory and disk space
- Install the chosen hypervisor

## How it will be checked

- A test virtual machine starts and runs
