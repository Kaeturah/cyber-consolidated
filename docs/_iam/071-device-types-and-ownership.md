## What this step is

Defining the device types: standard staff laptops, admin workstations, shared branch devices and test devices.

## Why it matters for Via Wash

A shared Operations device at a branch and an IT admin’s workstation need different rules. Defining the types first keeps the policies sensible.

## What will be done

- List the device types and who owns each
- Decide how each type is named and grouped

## How it will be checked

- Every planned device fits one type
