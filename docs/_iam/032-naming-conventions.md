## What this step is

A naming convention: agreed patterns for user accounts, admin accounts, groups and devices.

## Why it matters for Via Wash

Names show up everywhere: in logs, alerts and reports. When an alert mentions an account or device, a consistent name shows straight away what it is and whether it should be doing what it did.

## What will be done

- Choose patterns for staff accounts, admin accounts and groups
- Choose a pattern for devices that shows type and location
- Write the patterns down with an example of each

## How it will be checked

- Every object created later can be named with the patterns
- An admin account can never be mistaken for an everyday account
