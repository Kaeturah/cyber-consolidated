## What this step is

Creating the new starter’s account, in Entra ID and, for the on-premises route, in Active Directory.

## Why it matters for Via Wash

The account is what everything else attaches to, and the department field is what drives group membership.

## What will be done

- Create the account following the naming convention
- Fill in department, job title and manager
- Set a temporary password for the first sign-in

## How it will be checked

- The account exists with the correct details
