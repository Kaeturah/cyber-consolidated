## What this step is

Creating the user accounts for Via Wash’s people in Entra ID, with their department and job title filled in.

## Why it matters for Via Wash

Users are what everything else attaches to. Filling in the department correctly matters, because it drives group membership later.

## What will be done

- Create one or more named test users per department
- Fill in department, job title and manager
- Assign licences only where a user needs one

## How it will be checked

- Each user appears with the right department and licence
