## What this step is

Creating a compliance policy (the rules a device must meet) and configuration profiles (the settings it should have).

## Why it matters for Via Wash

Compliance is what lets Conditional Access say “only from a healthy device”. Configuration keeps every device set up the same way.

## What will be done

- Create a compliance policy, for example requiring encryption and a minimum Windows version
- Create one narrowly scoped configuration profile
- Check the result on the device

## How it will be checked

- The device reports compliant, or non-compliant for a known reason
