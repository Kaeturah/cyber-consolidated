## What this step is

Choosing the log sources to monitor: Entra sign-ins and audits, Defender alerts, device events and the Via Wash app’s own log.

## Why it matters for Via Wash

Detections can only see what is collected. Picking the right sources is the foundation of monitoring.

## What will be done

- List the available sources and what each shows
- Choose the tool, starting with what the licence includes
- Confirm each source is arriving

## How it will be checked

- Recent events from each chosen source can be queried
