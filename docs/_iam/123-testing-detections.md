## What this step is

Testing every detection with a deliberate, safe trigger and recording the result.

## Why it matters for Via Wash

A detection that has never fired might not work at all. Testing proves it, and shows what the alert looks like to an analyst.

## What will be done

- Trigger each detection safely, for example with failed sign-ins on a test account
- Record the alert and the time it took to appear

## How it will be checked

- Every detection has a recorded, successful test
