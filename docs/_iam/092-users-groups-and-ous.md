## What this step is

Creating organisational units (OUs) for departments, plus the users and groups inside them, following the naming convention.

## Why it matters for Via Wash

A tidy structure is what makes Group Policy and permissions manageable. It also keeps on-premises in line with the cloud design, which matters when the two are connected later.

## What will be done

- Create OUs for the six departments, and for computers
- Create test users and department security groups
- Record what each group is for

## How it will be checked

- Each test user sits in the right OU and groups

## Key terms

- **Organisational unit (OU)**: a container in Active Directory used to organise objects and apply policies
