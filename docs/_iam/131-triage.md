## What this step is

Triaging alerts: deciding if each one is real, how serious it is, and what happens next.

## Why it matters for Via Wash

Not every alert is an incident. Good triage spends time on what matters and closes the rest with a clear reason.

## What will be done

- Define severity levels for Via Wash
- Triage alerts from the simulated scenarios
- Record each decision and the reason
