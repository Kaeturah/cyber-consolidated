What this series is

Via Wash is a laundry and dry-cleaning pickup and delivery business in development, starting in London. Its customer app was already being built before this project started, so the business isn’t invented for the exercise. Its IT, though, is designed and tested in a Microsoft test environment first. Nothing here is a live production system yet.

The environment doesn’t get built all at once. Devices can’t be trusted until we know who uses them. Activity can’t be judged until we know what normal looks like. And an incident can’t be investigated properly in an environment nobody understands. So each stage gives the next something to stand on.

Read the chapters in order to follow the build, or jump to the one you need. Every chapter says plainly when it was written and how long it takes to read, and the ones still to come are marked as not started.
