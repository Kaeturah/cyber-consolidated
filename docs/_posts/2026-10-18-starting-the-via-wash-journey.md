Via Wash, the laundry pickup and delivery business whose app I have been building since September, is now the flagship project on this site.

The series is laid out like a book. It opens with who Via Wash is and what is being built, then the foundation work already done, then six build stages that run from identity and access through to incident response. Two more chapters cover the work that runs across the whole business: IT support and the security of the customer app.

Some chapters are documented, some are in progress and most are still planned. Planned chapters are visible on purpose, so you can see where the project is heading. Each one is marked plainly, and will only change status when there is real evidence to back it up.

Updates like this one will appear in the journal as the work happens.
