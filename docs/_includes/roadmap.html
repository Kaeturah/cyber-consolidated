Roadmap

Where the project is heading

These are the areas I intend to work through. They are a direction, not documentation: each one gets its own pages only once I have actually done the work and captured the evidence. The order and grouping may change as the project and my learning progress.

  1. Entra ID and identity management

    Building Via Wash’s users, groups, admin roles and sign-in protection in Entra ID. The planning is written up in Designing identity and access and Identity lifecycle, but nothing has been built in Entra ID yet.

    Implementation not started

  2. Intune and device management

    Bringing Via Wash’s devices under management, so the business knows which devices exist and whether they can be trusted. Details in Microsoft Intune.

    Done: initial Intune assessment; VW-Intune-Test-Devices group created and the test account added; automatic MDM enrolment limited to that group, saved and confirmed by Intune.

    Still to do: enrol a device; test configuration policies; test compliance policies. Device management has not been validated.

    Partly done · no device enrolled

  3. Defender and endpoint security

    Protecting managed devices and email, and proving the protection works with safe tests.

    Not started

  4. Windows configuration

    Preparing a suitable Windows test device and the settings Via Wash’s computers should have.

    Not started

  5. On-premises Active Directory

    The day-to-day IT many companies still run on their own servers, built in a small lab.

    Not started

  6. Hybrid identity

    Connecting on-premises identities to Entra ID, if the lab can support it.

    Not started

  7. A new starter, end to end

    Following one new employee from the HR request to a ready laptop, with access and apps arriving through groups.

    Not started

  8. Monitoring and detection

    Turning sign-ins, device events and alerts into detections that are tested to prove they fire.

    Not started

  9. Incident response

    Investigating and containing safe, simulated incidents across everything built before.

    Not started

  10. IT Support & Operations

    A distinct workstream within Via Wash’s IT department: support requests, access approvals, escalation and change records, so the environment stays usable and understandable.

    Not started

  11. Application security

    A safe review of the security already built into the Via Wash customer app. The existing work is documented in What the app already logs.

    Review outstanding
