## Why it matters

Technology only helps a business if people can use it, and get help when it stops working. IT support and operations is the function inside Via Wash’s IT department that makes the rest of the environment usable and maintainable. It is not a separate business department.

## How it connects to the build stages

| Process | Where it meets the build |
|---|---|
| New starters, role changes and leavers | Stage 1: accounts, groups and access change with the person. |
| Access requests and approvals | Stage 1: who can approve access to what. |
| Device setup and troubleshooting | Stage 2: enrolment, compliance and remote fixes. |
| Software requests | Stage 2: app deployment. |
| Suspicious email reported by staff | Stages 3 and 6: from a user’s report to an investigation. |
| Incidents and escalation | Stage 6: when a support issue turns out to be a security issue. |

## What it will cover

- Support requests and how incidents are handled
- User access and device support
- Approval and escalation workflows
- Records of assets and services
- Change and handover documentation, so every configuration change has a reason, a rollback plan and a test
